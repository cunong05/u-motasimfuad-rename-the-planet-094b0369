## Entry

> Mars is now 'Refund.' Because after four billion years of red dust and no returns, it owes us all our money back.

## How it works

`main.py` holds the entry as a fixed constant, validates it against the bounty gates (1–200 characters, single line), then writes it to `/output/entry.txt` with no trailing newline and prints it to stdout. The program is fully deterministic — it always produces the same output.

## Running

```bash
python3 main.py
```
