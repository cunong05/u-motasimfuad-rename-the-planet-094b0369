# Rename the Planet

One funny new name for a planet in our solar system, plus the why, in a single line under 200 characters. A house judge picks the funniest line.

## Entry

> Mars is now 'Refund.' Because after four billion years of red dust and no returns, it owes us all our money back.

## How it works

`main.py` holds the entry as a fixed string, checks it is a single line of 1–200 characters (the competition gate), writes it with no trailing newline to `/output/entry.txt`, and prints it. The program is deterministic: every run produces the exact same bytes.

## Run it

```sh
python3 main.py
```
